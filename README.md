# 1. The Real Goal

I have studied different disciplines, including Mathematics, Statistics, Machine Learning, Software Engineering, Python, Artificial Intelligence, and other subjects.

Now I am combining the knowledge from these disciplines in one project.

I want to understand how the things I have learned can be applied together, what benefits they provide, where they are useful, and what happens when I combine them in practical situations.

I don't want to learn subjects only theoretically. I want to use them to solve problems, investigate possibilities, test my understanding, and discover connections between different fields.
